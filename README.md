# 📝 TodoList

🔗 **Демо:** [Открыть веб-приложение](https://4tune16.github.io/TodoList/)

---

Веб-приложение для управления списком задач с локальным бэкендом.  
Позволяет создавать, удалять, искать задачи, изменять их статус и просматривать детали на отдельной странице.

---

## 🚀 Функциональность

- ✨ Создание, редактирование и удаление задач  
- 🔍 Поиск по названию с подсветкой найденных совпадений  
- ✅ Изменение статуса выполнения задачи  
- 📄 Просмотр подробностей задачи на отдельной странице  
- 🔄 Локальное хранение данных с использованием собственного бэкенда  
- ⚡ Оптимизация производительности и отзывчивый интерфейс  

---

## 🧩 Технологии

- **Frontend:** React, TypeScript, Vite, SCSS  
- **Backend:** Node.js (локальный сервер)  
- **Архитектура:** Feature-Sliced Design (FSD)  
- **API взаимодействие:** Fetch (GET, POST, DELETE, PATCH)

---

## ⚙️ Реализовано

- Построена архитектура проекта на основе **FSD-подхода**  
- Реализован **локальный бэкенд** и взаимодействие с ним через REST-запросы  
- Создан **кастомный роутинг** на базе History API  
- Оптимизирована производительность с помощью **useMemo**, **useCallback** и **React.memo**
